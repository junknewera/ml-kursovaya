# Прогнозирование активности соединений против вируса гриппа

Курсовая работа по машинному обучению: прогнозирование параметров эффективности 1001 химического соединения против вируса гриппа по молекулярным дескрипторам RDKit.

## Описание задачи и данных

Датасет содержит данные по 1001 молекуле (`data.xlsx`). Исходно каждая молекула описана 210 дескрипторами. После удаления 18 константных колонок осталось 192 дескриптора. Пропуски в данных (3 строки в 12 колонках) заполнены медианными значениями.

Целевые переменные:
- `IC50, mM` - концентрация полумаксимального ингибирования вируса (чем ниже, тем активнее соединение). Skewness: 3.67.
- `CC50, mM` - концентрация полумаксимальной цитотоксичности (чем выше, тем безопаснее соединение для клеток). Skewness: 1.97.
- `SI` (Selectivity Index) = CC50 / IC50 - индекс селективности (чем выше, тем лучше соотношение эффективности и безопасности). Skewness: 18.01.

В рамках проекта решено 7 задач:
1. Регрессия IC50
2. Регрессия CC50
3. Регрессия SI
4. Классификация IC50 > медианы
5. Классификация CC50 > медианы
6. Классификация SI > медианы
7. Классификация SI > 8 (порог отбора перспективных соединений, составляет 36% выборки)

## Подход и методология

- Разбиение данных: train/test split 80/20 с фиксированным `random_state=42`.
- Препроцессинг:
  - Удаление признаков с `nunique <= 1`.
  - Заполнение пропусков медианой по колонкам.
  - Масштабирование признаков через `StandardScaler` для линейных моделей, SVM и KNN. Для моделей на основе деревьев масштабирование не применялось.
  - Логарифмирование таргетов (`np.log1p`) в задачах регрессии для снижения скошенности распределений.
- Алгоритмы: LinearRegression, Ridge, Lasso, ElasticNet, RandomForest, GradientBoosting, SVR/SVC, LogisticRegression, KNeighborsClassifier.
- Оптимизация гиперпараметров: `GridSearchCV` с 5-кратной кросс-валидацией (`cv=5`) для RandomForest, GradientBoosting и SVC.
- Оценка качества:
  - Регрессия: R2, MAE, RMSE в log-пространстве и в оригинальной шкале после `expm1`.
  - Классификация: F1-score, ROC-AUC, Accuracy, Precision, Recall.

## Результаты

### 1. Регрессия: IC50

RandomForest показал лучший R2(log)=0.46. LinearRegression без регуляризации переобучается на 192 признаках. Топовые признаки по важности: VSA_EState8, VSA_EState4, MolLogP.

| Модель | R2 (log) | R2 (orig) |
|---|---|---|
| RandomForest (tuned) | 0.46 | 0.27 |
| GradientBoosting (tuned) | 0.43 | 0.28 |
| SVR | 0.36 | 0.27 |
| Lasso | 0.32 | 0.31 |
| Ridge | 0.28 | 0.23 |
| LinearRegression | -0.08 | -33.9 |

### 2. Регрессия: CC50

CC50 предсказывается точнее остальных таргетов. GradientBoosting лучше всех восстанавливает оригинальные значения (R2=0.51). Значимые признаки: VSA_EState8, Kappa1, NHOHCount.

| Модель | R2 (log) | R2 (orig) |
|---|---|---|
| RandomForest (tuned) | 0.44 | 0.49 |
| GradientBoosting (tuned) | 0.37 | 0.51 |
| SVR | 0.39 | 0.50 |
| Lasso | 0.35 | 0.30 |
| Ridge | 0.32 | 0.30 |
| LinearRegression | 0.17 | -1.90 |

### 3. Регрессия: SI

Наиболее сложная задача регрессии. В log-шкале лучший результат у RandomForest (R2=0.34). В оригинальной шкале R2 около нуля у всех моделей из-за единичных экстремальных выбросов (максимальный SI=15620).

| Модель | R2 (log) | R2 (orig) |
|---|---|---|
| RandomForest (tuned) | 0.34 | 0.003 |
| GradientBoosting (tuned) | 0.31 | -0.002 |
| SVR | 0.20 | -0.007 |
| Ridge | 0.10 | -0.008 |
| LinearRegression | -0.10 | -0.007 |

### 4. Классификация: IC50 > медианы

SVC показал наибольший F1 (0.75), ансамбли деревьев лидируют по ROC-AUC (0.79-0.80).

| Модель | F1 | ROC-AUC |
|---|---|---|
| SVC (tuned) | 0.75 | 0.77 |
| RandomForest (tuned) | 0.73 | 0.79 |
| GradientBoosting (tuned) | 0.71 | 0.80 |
| LogisticRegression | 0.72 | 0.75 |
| KNN | 0.68 | 0.75 |

### 5. Классификация: CC50 > медианы

Наилучшая разделимость среди всех задач классификации. RandomForest показал F1=0.81 и ROC-AUC=0.89. В топе признаков: NHOHCount и BCUT2D_MWLOW.

| Модель | F1 | ROC-AUC |
|---|---|---|
| RandomForest (tuned) | 0.81 | 0.89 |
| KNN | 0.79 | 0.85 |
| SVC | 0.78 | 0.86 |
| GradientBoosting | 0.78 | 0.87 |
| LogisticRegression | 0.76 | 0.85 |

### 6. Классификация: SI > медианы

Качество классификации SI ниже, чем для IC50 и CC50. KNN с k=5 показал лучший F1 (0.66), подбор гиперпараметров для KNN результат не улучшил.

| Модель | F1 | ROC-AUC |
|---|---|---|
| KNN (k=5) | 0.66 | 0.71 |
| RandomForest | 0.64 | 0.74 |
| SVC | 0.63 | 0.70 |
| GradientBoosting | 0.63 | 0.70 |
| LogisticRegression | 0.63 | 0.67 |

### 7. Классификация: SI > 8

Из-за умеренного дисбаланса классов использовался параметр `class_weight="balanced"`. Базовый порог 0.5 дает F1=0.56 у SVC и RandomForest. Подбор порога вероятности для SVC показал, что при снижении порога до 0.30 значение Recall вырастает с 0.39 до 0.61, а F1 достигает 0.58.

| Модель | F1 | ROC-AUC |
|---|---|---|
| SVC (balanced) | 0.56 | 0.70 |
| RandomForest (balanced) | 0.56 | 0.71 |
| LogisticRegression (balanced) | 0.53 | 0.69 |
| KNN | 0.52 | 0.71 |
| GradientBoosting | 0.50 | 0.70 |

## Структура файлов

- `data.xlsx` - исходный датасет с дескрипторами и целевыми переменными.
- `utils.py` - функции загрузки данных (`load_data`), выделения признаков (`get_features_targets`) и формирования train/test выборок (`get_regression_split`, `get_classification_split`).
- `01_eda.ipynb` - разведочный анализ данных: анализ распределений, выбросов по IQR, мультиколлинеарности и PCA.
- `02_regression_ic50.ipynb` - обучение и оценка моделей регрессии для IC50.
- `03_regression_cc50.ipynb` - обучение и оценка моделей регрессии для CC50.
- `04_regression_si.ipynb` - обучение и оценка моделей регрессии для SI.
- `05_classification_ic50_median.ipynb` - классификация IC50 относительно медианы.
- `06_classification_cc50_median.ipynb` - классификация CC50 относительно медианы.
- `07_classification_si_median.ipynb` - классификация SI относительно медианы.
- `08_classification_si_8.ipynb` - классификация соединений по критерию SI > 8 и анализ порогов решений.
- `report.pdf` - отчёт по результатам выполнения курсовой работы.

## Инструкция по запуску

Для работы ноутбуков требуются следующие Python-библиотеки:
- `pandas`
- `numpy`
- `scikit-learn`
- `matplotlib`
- `seaborn`
- `openpyxl` (для чтения файла `data.xlsx`)

Установка зависимостей:

```bash
pip install pandas numpy scikit-learn matplotlib seaborn openpyxl
```

Ноутбуки независимы друг от друга и запускаются из корня репозитория в Jupyter: данные и общие функции берутся из `data.xlsx` и `utils.py`.
